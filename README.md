# 🌍 Travel Explorer — MERN Stack

A full-stack **Travel Booking Platform** built with the **MERN stack (MongoDB, Express.js, React.js, Node.js)** that allows users to explore hotels, filter them by rating, people count, discount, and more — with seamless UI and API integration.

![travel-banner](https://via.placeholder.com/1000x300?text=Travel+Explorer+App+%7C+MERN+Stack) <!-- Replace with actual screenshot if available -->

---

## 🚀 Features

- 🏨 **Hotel Listings** — Browse dynamic hotel cards with details like mood, rating, discount, and capacity  
- 🔍 **Advanced Filtering** — Search and filter hotels by rating, city, discount, people count, etc.  
- 🧠 **Smart Chatbot** — Integrated hotel recommendation bot using filters and dynamic data  
- 🌐 **RESTful API** — Backend API to serve hotel and booking data  
- 🔐 **User Authentication** *(optional if implemented)* — Secure login & session flow  
- ⚡ **Optimized Performance** — Clean UI + efficient API requests for fast load times
